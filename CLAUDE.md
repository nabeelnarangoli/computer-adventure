# Project rules (Aqlyon Digital Skill Academy)

- Never deploy straight away. Commit and push to `staging` only; merge `staging` into `main` (which deploys on Netlify) only when the owner says "deploy". Deploy all changes together.
- Every course, including any course added later, follows the same learning method:
  - A short set of questions first builds the learner's path (computer course: "About you" + quick check; programmes: level check).
  - Lessons/stages open one at a time: only the next one opens after the previous is finished (computer lesson marked finished, programme stage quiz passed). Locked tiles are not clickable.
  - A level check / quick check may open the levels or units it proved; that is intended.
  - Every learn step has a "Watch how" demo with step-by-step captions.
  - The mascot appears on the same screens (welcome, course choice, level check, result, quiz, locked, certificate, help).
- Spelling: "Aqlyon Career Discovery Centre" (Centre, not Center).
